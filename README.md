[Fortune in a Pot bounty](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9)

## The fortune

> "This spring, a stranger will admire you through the glass, and your keeper will finally water you on purpose."

## How to run

```sh
python3 main.py
```

The program writes the fortune to `/output/entry.txt` (UTF-8, one line, 109 characters — inside the 1–120 character gate).
